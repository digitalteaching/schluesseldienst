# Schlüsseldienst

Interaktive Unterrichtsseite zur Verschlüsselung für Informatik in Klasse 10: verschlüsseln, knacken, eigene Tresore bauen und tauschen.
Eine einzelne HTML-Datei ohne Server und ohne Konten, passwortgeschützt (die Seite liegt verschlüsselt im Repository).

Seite: https://digitalteaching.github.io/schluesseldienst/
